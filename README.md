# playyard

Small text playgrounds, written in one Python file each. Nothing to install
beyond Python 3.9.

The ideas come from three projects I had forked and never touched:

- [DulLabs/bhai-lang](https://github.com/DulLabs/bhai-lang), a toy language
  whose keywords are Hindi. `playyard bhai` runs a small slice of it.
- the habit of keeping a plain-text log of the day. `playyard digest` adds up
  where the time went.
- [Metroxe/one-html-page-challenge](https://github.com/Metroxe/one-html-page-challenge).
  `playyard page` emits one HTML file with the styling inlined, so there is
  nothing to build and nothing to fetch.

## Try it

```sh
python3 -m playyard bhai   examples/hello.bhai
python3 -m playyard digest examples/day.log
python3 -m playyard page "Playyard" examples/page.txt > page.html
```

`bhai` understands `bol` (print), `name = value`, arithmetic with `+ - *`
evaluated left to right, and one `jab tak ... bas` loop. The comparison is
checked before the loop runs, so a condition that is already false does
nothing. `digest` reads lines like `09:10-09:40 write the readme` and groups
them by whole words, so "readme" stays writing and "read" stays learning.

## Demos

Three pages generated by `playyard page` itself, checked in so you can open
them with no Python at all:

- [Counting in bhai](docs/counting.html) runs `examples/hello.bhai` and shows the output.
- [Where Saturday went](docs/saturday.html) is `examples/day.log` after the digest.
- [Why playyard](docs/why.html) is who it is for and what it leaves out on purpose.

`docs/LINKEDIN.md` is a short note about the same thing, written to be posted.
The github.io links in it do not work until GitHub Pages is enabled for this
repo's `docs/` folder on `main`; until then, open the files from a clone.

Rebuild the pages after changing an example:

```sh
python3 -m playyard page "Counting in bhai" examples/counting.txt "one loop, then done" > docs/counting.html
python3 -m playyard page "Where Saturday went" examples/saturday.txt "a day log, added up" > docs/saturday.html
python3 -m playyard page "Why playyard" examples/why.txt "small on purpose" > docs/why.html
```

## Tests

```sh
python3 -m unittest discover -s tests
```

## What it deliberately does not do

`bhai` is not a faithful bhai-lang: there is one loop, no functions, and no
nested expressions. `digest` guesses themes from a short word list. Both are
small enough to read straight through, which was the point.
